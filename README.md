# Sistema de Gestión para Concurso de Danzas

Sistema web desarrollado en Python Flask para gestionar un concurso de danzas con dos categorías (A y B).

## Características

- ✅ Login de administrador
- ✅ Dashboard con estadísticas
- ✅ CRUD de participantes
- ✅ Registro de calificaciones (3 jurados)
- ✅ Cálculo automático de puntaje total
- ✅ Ranking automático por categoría
- ✅ Visualización de resultados
- ✅ Exportación a Excel
- ✅ Diseño responsive con Bootstrap 5

## Requisitos del Sistema

- Python 3.8 o superior
- MySQL 5.7 o superior
- pip (gestor de paquetes de Python)
